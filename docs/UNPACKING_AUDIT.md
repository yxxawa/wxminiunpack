# 解包与源码重建检查（2026-11-23）

使用本机微信缓存作为只读输入，用独立 Python 脚本按字节解密、读取索引，再与 C++ 实现对照。未执行样本中的 JavaScript，未修改原始缓存，未将真实包内容加入测试夹具。

## 发现与修复

- **索引边界偏移**：真实包的索引长度包含文件数量字段，结束位置应为 `14 + indexLength`，原实现使用 `18 + indexLength`。修正边界并检查文件数、文件名、正文长度和正文偏移，避免损坏索引越界或申请过多内存。
- **重复插件文件项**：一个真实插件包重复记录了内容相同的 `plugin.json`。允许完全相同的重复内容，拒绝映射到同一 Windows 路径但内容冲突的条目。
- **格式误判**：原实现将所有未知格式当成加密包。现在只接受已识别的明文头或 `V1MMWX`，并明确提示错误 WXID。
- **重建遗漏**：补充游戏及插件 JS 容器、内嵌 JSON 和 WXSS 的静态提取。JS 词法读取处理注释、字符串、正则表达式及嵌套模板字符串，支持带空白或注释的 `define()`。
- **配置与路径丢失**：保留插件声明、小游戏 `openDataContext`、跳转声明及原始文件；插件模块与资源统一使用 `__plugin__` 路径。整理页面、分包及页面配置时保留原有信息。
- **虚假页面与成功状态**：取消自动生成空 JS、`component: true` 和占位 WXML；增加 `reconstruction-report.json`，缺失模板和处理失败计入“部分完成”。
- **手动导入旧版本优先**：同名包按数字版本号降序处理，历史版本单独保留。
- **测试失效**：Release 模式原先会禁用 `assert`。现有核心测试显式开启断言，新增独立重建回归测试，并修正合成包夹具的索引长度。
